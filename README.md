## Editorial conventions

- Every catalogue row uses the repository's **Title | Method/Model | Date | Code | Venue** format.
- A title link is drawn only from the supplied BibTeX record: its explicit URL, DOI, or an arXiv identifier encoded in the record. Plain titles intentionally have no invented landing page.
- A `[repo]` link appears only where that record explicitly points to a GitHub repository. `—` means **no source-code repository was verified from the supplied record**; it is not a claim that no implementation exists.
- The small `bib:` identifier in each Method/Model cell provides a stable trail back to the supplied source bibliography.
